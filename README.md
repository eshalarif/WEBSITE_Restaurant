# Lahori Kitchen

Lahori Kitchen is a full-stack restaurant website that allows customers to browse delicious meals and place orders online.

## Features

* Browse the restaurant menu
* View meal names, descriptions, and prices
* Add meals to an order
* Submit customer and delivery information
* Place orders online
* Navigate the website on desktop and mobile devices

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Node.js
* Express
* MongoDB

## How to Use the Website

### 1. Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/eshalarif/WEBSITE_Restaurant.git
```

### 2. Open the Project Folder

```bash
cd WEBSITE_Restaurant/Project_Part2-main
```

You can open the project in Visual Studio Code by running:

```bash
code .
```

### 3. Install the Main Project Dependencies

```bash
npm install
```

### 4. Install the Client Dependencies

```bash
cd client
npm install
```

### 5. Return to the Main Project Folder

```bash
cd ..
```

### 6. Start the Application

```bash
npm start
```

After the application starts, open the local address displayed in the terminal. This is commonly:

```text
http://localhost:3000
```

## Using Lahori Kitchen

1. Open the website in your browser.
2. Browse the available meals.
3. Select the meals you would like to order.
4. Review your order.
5. Enter the required customer and delivery information.
6. Submit your order.

## Project Purpose

This project was created to demonstrate full-stack web development, responsive design, online ordering functionality, and the connection between a restaurant website’s frontend and backend.
